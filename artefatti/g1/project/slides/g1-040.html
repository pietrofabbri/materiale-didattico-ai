Un formato semplice per i dati

Il formato CSV

File › Scarica › Valori separati da virgola (.csv). Aperto con un editor di testo, il file è così:

  • una riga per ogni frase
  • le colonne separate sempre dallo stesso simbolo (qui il punto e virgola)
  • la prima riga contiene i nomi delle colonne

id;gruppo;genere;frase;tipo;fonte
1;1;meteo;il vento soffia forte al nord;fatto;aeronautica militare
2;1;meteo;…
